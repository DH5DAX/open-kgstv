# HamRig Robbie

`hamrig-robbie.png` is the original transparent Robbie artwork from the project
owner's HamRig Portal (`hamrig-robbie-solo-transparent.png`), included at their
request for the Open KG-STV header and window icon. The source image is unchanged;
the application scales it at runtime.

Robbie is HamRig branding. This project's MIT license for its own code and
documentation does not grant a separate license to the HamRig artwork or marks.
